# Vision & Scope для "Личного кабинета"
## 1. Vision
Создать удобный и безопасный раздел «Личный кабинет пользователя», который обеспечит пользователям доступ к персональной информации, истории заказов и настройкам, повысит их удовлетворённость за счёт удобства и быстроты и снизит нагрузку на службу поддержки. 

## 2. Бизнес-цели
+ повысить удовлетворённость пользователей за счёт удобства и прозрачности на N% через 3 месяца после релиза MVP;
+ сократить нагрузку на службу поддержки на N% за полгода;
+ повысить лояльность и удержание клиентов на N% в течение года;
+ получить дополнительные данные о поведении пользователей для анализа, чтобы понимать, как они взаимодействуют с сервисом.

## 3. Scope

### 3.1 In Scope (равно MVP)
1. Регистрация и авторизация
+ Регистрация по email/телефону
+ Вход через логин и пароль
+ Восстановление пароля
2. Профиль пользователя
+ Просмотр и редактирование личных данных (ФИО, контакты)
+ Настройка уведомлений
3. История заказов
+ Просмотр списка заказов
+ Просмотр деталей конкретного заказа (дата, статус, сумма, состав)
4. Поддержка
+ Обратная связь через форму или чат
+ Раздел с часто задаваемыми вопросами 
5. Уведомления
+ Отображение системных уведомлений (например, «заказ доставлен», «изменен пароль»)
6. Аналитика (для бизнеса)
+ базовая статистика: количество активных пользователей, количество авторизаций, действия в кабинете

### 3.2 Out of Scope (Не входит в MVP)
+ онлайн-оплата и управление платежами;
+ программа лояльности и бонусные баллы;
+ персонализированные предложения;
+ интеграция с CRM или внешними системами;
+ мобильное приложение (на этапе MVP только веб-версия);
+ расширенные отчёты 

## 4. Основные ограничения
+ реализовать MVP за 3 месяца;
+ интерфейс должен быть простым и адаптивным (десктоп и мобильная версия сайта);
+ время отклика до 2 секунд при типичных действиях;
+ соблюдение требований по защите персональных данных 

## 5. Участники проекта
Бизнес-заказчик: руководитель продукта.
Пользователи: зарегистрированные клиенты компании.
Команда разработки: системный аналитик, фронтенд, бэкенд, QA, дизайнер UX/UI.
Поддержка: контакт-центр.

## 6. Критерии успеха проекта
+ MVP запущен в срок, и система работает стабильно (доступность не ниже 99%);
+ не менее 60% зарегистрированных пользователей активировали личный кабинет;
+ уровень удовлетворенности не ниже 80%;
+ количество обращений в поддержку по базовым вопросам снизилось минимум на 25%
